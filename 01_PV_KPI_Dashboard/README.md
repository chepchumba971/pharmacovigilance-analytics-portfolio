Pharmacovigilance KPI Dashboard
Project Overview

This project demonstrates the development of a Pharmacovigilance Key Performance Indicator (KPI) Dashboard using synthetic adverse event data.

The objective is to monitor drug safety reporting trends and support evidence-based decision-making through interactive visualizations.

Business Problem

Pharmacovigilance teams process large volumes of Individual Case Safety Reports (ICSRs). Effective monitoring of case volume, seriousness, product distribution, and reporting trends is critical for maintaining compliance and patient safety.

Objectives

Monitor total case volume
Analyze serious versus non-serious cases e,g Adverse events of special interest
Evaluate product-level reporting trends
Assess country distribution of reports
Track monthly reporting activity
Tools
Excel
Power BI

Dataset

Synthetic pharmacovigilance data created for educational and portfolio purposes only.
